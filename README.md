# ⚡ Instant GitHub-Style Username Generator

A lightweight, dark-themed Python desktop app that generates random, GitHub-style usernames. It uses pre-compiled WordNet semantic word pools to give you near-infinite, themed combinations without annoying word repetitions or laggy startup times.

![Python](https://img.shields.io/badge/Python-3.8+-3776AB?style=flat&logo=python&logoColor=white)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-blue)

---

## ✨ Features

- **5 Distinct Themes:** Cyberpunk/Tech, Sci-Fi/Space, Fantasy/Mythic, Gaming/Esports, and Nature/Wild.
- **Fast & Lightweight:** Words are pre-compiled into a local JSON cache—no waiting on downloads or heavy NLP libraries at runtime.
- **Near-Infinite Possibilities:** Choose between 2-word, 3-word, or hybrid patterns (adds numbers) to get virtually endless combinations.
- **One-Click Copy:** Built-in copy-to-clipboard button formatted cleanly for GitHub repo names, gaming handles, or online accounts.
- **GitHub Dark Theme:** Clean UI built with Tkinter.
